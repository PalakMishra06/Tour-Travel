# 🌍 Tour & Travels Website

A static front-end website for a Tour & Travels agency. It showcases various travel destinations and packages with an attractive UI built using HTML, CSS, and JavaScript.

> ⚠️ This project is **not responsive** (does not adapt for mobile or tablet screens).

---

## 📁 Project Overview

This is a basic frontend project with no backend functionality. It demonstrates the layout and structure of a typical travel agency website, suitable for portfolio or learning purposes.

---

## 🛠️ Technologies Used

- **HTML5** – For structure
- **CSS3** – For styling
- **JavaScript** – For basic interactivity (if any)

---

## 🎯 Key Sections

- 🏠 Home Page with intro banner
- 🌄 Destinations showcase
- 💼 Tour Packages grid
- 📞 Contact Us or Booking form (non-functional)
